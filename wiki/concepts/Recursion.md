# Recursion

A technique where a function calls itself to solve smaller subproblems until reaching a base case. Essential for tree traversals, divide-and-conquer algorithms, and problems with recursive structure.

## Appearances in Sources
- [[trees]] — all three depth-first traversal methods (preorder, inorder, postorder) are recursive
- [[oop-game]] — `validated_prompt()` recurses on invalid user input
