# What data structures have I studied?

## Implemented
1. **[[LinkedList]]** (via [[linked-list]]) — Singly linked list with append, prepend, insert-after, delete, and iterative reversal. Uses `Node` objects with data/next pointers.
2. **[[BinaryTree]]** (via [[trees]]) — Binary tree with preorder, inorder, and postorder depth-first traversals using [[Recursion]].

## Implicitly Used
- **Python list** — used as the backing store in [[bubble-sort]]'s `LineList` class, but not implemented from scratch.

## Not Yet Covered
- Hash tables / dictionaries
- Stacks
- Queues / deques
- Heaps / priority queues
- Graphs
- Doubly linked lists (file exists at `raw/` but is empty)
